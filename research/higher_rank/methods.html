Rank-five and rank-six finite T-data

The completed classifications contain 55 indecomposable rank-five families and 108 rank-six families, with identity symmetrizer and diagonal leading matrix. The arguments below combine finite constant enumeration, unbounded polynomial-lift checks and exact mutation certificates.

A finite search over coefficient sums

Write P = N+(1), M = N−(1), so A+(1) = 2I − P and A−(1) = 2I − M. The necessary positivity theorem gives a row vector v > 0 with v(2I − P) > 0 and v(2I − M) > 0. Indecomposability makes the union support graph strongly connected, by the lowest-degree crossing argument in the rank-four manuscript.

Every off-diagonal weight wᵢⱼ = max(Pᵢⱼ,Mᵢⱼ) obeys wᵢⱼvᵢ < 2vⱼ. Multiplying around a simple directed cycle bounds its product by 2r in rank r. Since its weights are positive integers, every coefficient sum is at most 2r − 1. Diagonal sums are zero or one.

Relabel so v₁ ≥ ··· ≥ vᵣ. Above the diagonal, each column of P or M is zero or has a single 1, with the latter forcing its diagonal entry to be zero. Thus each upper-triangular part has (r+1)! possibilities. The enumerator processes all unordered pairs, then solves the constant symplectic identity row by row using exact adjugates and divisibility tests. Positive principal minors make each solved leading block invertible.

Stronger bounds from the ordered positive vector

For a known upper arrow i → j, one has vᵢ < 2vⱼ. Moving from a larger index to a smaller one uses the inequality vᵢ ≤ vⱼ with no factor. Let d be the smallest number of upper arrows in a path from k to j, allowing those free backwards moves. Then vₖ ≤ 2dvⱼ, and hence every lower weight in position (j,k) satisfies

wⱼₖ < 2d+1,   wⱼₖ ≤ 2d+1 − 1.

These paths depend only on the fixed upper triangles and can be computed before enumerating lower rows. For example, an arrow from the first to the last species makes d = 1 for every lower position, reducing every lower bound to 3. Strong connectivity guarantees an upper arrow across each ordered cut, so these bounds are finite.

The same distances give the lower bound vᵢ ≥ 2−d(k,i)vₖ. For each sign C = P or M, the necessary column inequality therefore implies ΣᵢCᵢₖ2−d(k,i) < 2. Before assigning a new lower row, its known column contributions reduce the individual entry bounds. Multiplication by 2r makes these strict inequalities integral. These bounds reproduce exactly all 460 rank-four and 4,697 rank-five reference candidates.

The unknown M row is an affine-linear function of the unknown P row. Bounds on its entries and positivity of the next leading determinant therefore give linear inequalities. Interval bounds on unassigned row entries discard only branches that cannot satisfy these necessary inequalities. The final candidate still passes the original integer cycle and principal-minor checks.

The parity lemma is also applied as soon as a row is complete: every diagonal entry of (2I − P)(2I − M)T is even. This follows because the corresponding reciprocal Laurent polynomial has constant coefficient 2 and its nonzero powers occur in equal pairs.

Finally, exact extreme rays test the ordered simultaneous-positive cone. Canonicalization exhausts index permutations and exchange of signs. The generalized enumerator reproduces exactly the 460 parity-compatible rank-four candidates obtained by the earlier implementation.

Polynomial lifts without a delay cutoff

Excluding a principal subdatum by the lower-rank classification

Let S be a set of species. Suppose that, for each column k outside S, either N+[S,k] = 0 or N−[S,k] = 0. Every exterior-column contribution to the symplectic identity restricted to rows S is then zero. Consequently the principal matrices A±[S,S] themselves form a T-datum.

Simultaneous positivity passes to this principal subdatum: deleting an exterior row removes a nonpositive contribution to each column product vA±. Split its union support into weakly connected components. Each component is therefore an indecomposable T-datum with simultaneous positivity.

In ranks at most five, the completed lower-rank lift analysis classifies all such polynomial data under simultaneous positivity, and every surviving lift family is periodic. Hence the constant pair of each component must occur among the corresponding lower-rank catalogue constants, up to permutation and sign exchange. A missing pair is an exact obstruction. The saved witness identifies S, the zero sign in every exterior column, and the offending component. This argument uses the lower-rank positivity classification; it does not assume that restriction preserves periodicity in general.

For rank six this test also runs inside the constant enumerator, as soon as a leading principal block is fully assigned and its exterior columns satisfy the sign condition. Each weak component is looked up in a table containing every relabeling and sign exchange of the completed rank-one through rank-five constants. Failure discards the whole extension branch. The accompanying control report verifies that all 37 rank-four and 55 rank-five families survive this pruning.

The retained rank-six candidates combine earlier unpruned checkpoints with subsequently pruned tasks. Every possible positive polynomial lift is still represented, but their count is the number of retained candidates, not the size of the unpruned parity-compatible constant set. The completed task files identify which pruning rules were used.

A monomial tree and one extra species

After possibly exchanging signs, suppose N+ vanishes on all rows except an extra species ℓ, and initially assume (N+)ℓℓ = 0. On the other species, let N− have symmetric binary coefficient sums, with its off-diagonal support a connected tree. Diagonal monomials are allowed. Suppose its only arrow from that tree to ℓ is a single monomial at a → ℓ.

The translated-binomial identities give a common tree delay R. Diagonal monomials have exponent R/2. Species shifts can center every tree edge at exponent R/2 because the graph is a tree. These shifts may produce Laurent monomials; all coefficients remain nonnegative, and opposite signs remain disjoint.

Write q = zR/2, F = 1 + q², and let C be the tree’s symmetric binary coefficient matrix, including any diagonal loops. Let Tᵢ = (N+)ℓᵢ(z−1) and Uᵢ = (N−)ℓᵢ(z−1) in these shifted coordinates. The attaching monomial gives H = zᵇ(1 + z−rℓ). The equations between the tree and ℓ are

F(T − U) − qCT = −eₐH.

At the smallest exponent among T, U and H, the terms multiplied by q or q² contribute nothing. Disjoint support therefore forces that exponent to be min deg H = min deg Uₐ, with the same nonzero coefficient. At the largest exponent after subtracting R from deg H, the q² terms give similarly max deg Uₐ = max deg H − R.

Thus Uₐ cannot vanish. If its coefficient sum is one, it is a monomial; the two extremal equalities give rℓ = R and FUₐ = H. Define U′ = U − eₐUₐ. The equation becomes F(T − U′) = qCT. Comparing the smallest exponent of any nonzero T or U′ forces equal coefficients in opposite signs, contrary to disjoint support. Hence T = U′ = 0.

This excludes a reverse coefficient (N−)ℓₐ(1) of zero. If that coefficient is one, it excludes every case with any N+ support from ℓ to the tree, or any further N− support from ℓ to a different tree vertex. The argument is independent of rank and of the numerical delays.

The reverse-coefficient-zero exclusion also holds when N+,ℓℓ is nonzero: replace H by the attaching monomial times (1 + z−rℓ − N+,ℓℓ(z⁻¹)). The support condition puts every new negative term strictly between its two positive extremal terms. The least-exponent argument still forces Uₐ to be nonzero. The stronger reverse-coefficient-one conclusion above retains the hypothesis N+,ℓℓ = 0.

Each unit of a coefficient sum receives an exponent variable. Delays are positive; a row-i exponent satisfies 0 < p < rᵢ; opposite signs have disjoint support. The symplectic identity is equality of finite multisets of affine-linear Laurent exponents. The solver encodes equality of their multiplicities. Thus UNSAT excludes the constant pair at all delays.

Necessary linear consequences are included to simplify these queries. If a reciprocal off-diagonal pair consists of same-sign monomials and every opposite-sign cross product between the two rows vanishes, the identity is an equality of translated binomials. Their delays agree and the two exponents sum to that delay. Two zero rows of the other sign are a special case. If each off-diagonal entry of a row uses only one sign and exactly one diagonal support monomial occurs, its exponent is half the row delay. Both assertions follow by comparing the least and greatest exponents of the corresponding reciprocal identity.

Both integer arithmetic and rational arithmetic are available. For the latter, normalize Σᵢrᵢ = 1. All identities and support inequalities are homogeneous, so a rational solution can be scaled to an integer solution; conversely an integer solution normalizes to a rational one. This change of arithmetic preserves feasibility.

A solution groups equal Laurent exponents. The resulting homogeneous linear equations define a matching space on which the symplectic identity holds identically. An outside-space query searches for any remaining lift. A complete family classification requires this query to be UNSAT and every maximal space to equal the span of its time rescaling and species shifts. A separate mutation calculation must then certify finite type of its representative.

Finite reduction for a single attached species

Extreme support of the new row

Let ℓ be the extra species and S its complement. After exchanging signs if needed, assume N₊[S,ℓ] = 0 and N₋[S,ℓ] = zᵇeₐ for one a ∈ S. Put B± = A±[S,S], and let T and U be the column vectors with entries N₊,ℓᵢ(z⁻¹) and N₋,ℓᵢ(z⁻¹), respectively. The restricted symplectic identity is

B₋T − B₊U = −zᵇeₐ (1 + z−rℓ − N₊,ℓℓ(z⁻¹)).

The constant matrices B±(0) are identity matrices. Comparing the globally least exponent on the two sides forces the least exponent of T or U to be b − rℓ, attained only in Uₐ, with coefficient one. For the largest exponent d of T or U, choose a component i attaining it. Its diagonal term at d + rᵢ exceeds the degree of every other term in that row, since each entry of N± on row i has degree strictly below rᵢ. Hence i must be a, and d = b − rₐ; this endpoint too occurs only in Uₐ, with coefficient one.

In the original polynomial coordinates, the first and last exponents in N₋,ℓₐ are rₐ − b and rℓ − b. Every support term in the other entries of the new row lies strictly between these endpoints. In particular, the reverse coefficient cannot be zero. If it is one, rℓ = rₐ and all other off-diagonal entries on row ℓ vanish. This argument requires no tree assumption on the core.

Normalize the classified core and enumerate its forcing pulses

The exterior-column condition makes B± a principal T-datum. When this core is indecomposable, its complete lower-rank lift classification puts it, after a positive rational scale λ and species shifts, in the form of a recorded pair C± with integral polynomial exponents. These shifts may make the new row Laurent; they preserve its coefficient sums, nonnegativity and disjointness.

Translate the common origin of the new-row vectors to their least exponent, and normalize time by λ. The equation becomes

C₋Φ − C₊Ψ = eₐ (−1 + εzᴸ − zᴿ),
R = rℓ/λ,   ε ∈ {0,1},   0 < L < R when ε = 1.

Here ε is the coefficient sum of N₊,ℓℓ. If that entry is zᵖ, then L = (rℓ − p)/λ. The vectors Φ and Ψ have finite support, nonnegative integral coefficients and disjoint support in each component. Their least exponent is zero and their largest exponent is R − ρₐ, where ρₐ is the normalized core delay at a.

All exponents of C± are integers, so the coefficient equations separate into cosets modulo ℤ. A coset without a forcing pulse has no nonzero finite solution, by its least term. A coset with exactly one pulse also has no finite solution: the same extremal argument would make its greatest exponent smaller than its least exponent by ρₐ. If the two or three displayed pulses did not all lie in one coset, some coset would contain exactly one. Thus R and, when present, L are integers.

Write wd = Φd − Ψd. Since C±(0) = I, the coefficient equation at d determines wd from earlier coefficients and the forcing pulse. Disjointness then forces Φd = max(wd,0) and Ψd = max(−wd,0), component by component. This is a deterministic integer recurrence.

Let h be the maximum core delay and let S₀ be the total prescribed coefficient sum in the new row outside its diagonal. The recurrence has memory at most h. A block of h zero coefficient vectors before the last pulse would leave either the first pulse as a finite response, or the last pulse as an uncancelled single-pulse response; both are impossible by the preceding argument. Every such block therefore contains at least one unit of coefficient mass. It follows that

1 ≤ R ≤ (S₀ + 1)h.

This is a proved bound relative to the core scale; λ remains unrestricted. Enumerating these R and the integers 0 < L < R covers every possible finite response. Once the coefficient totals exceed the prescribed ones, a branch is impossible. A zero memory state after the last pulse proves that the remaining tail is zero. The calculation tests only the necessary core-row subsystem: an empty list excludes the original datum, while a nonempty list alone makes no finite-type claim.

The pulse enumerator reproduces 398 independently settled rank-five exclusions and the normalized delays of 62 rank-five and 110 rank-six positive attachment instances. The controls are recorded here. Every rank-six pulse exclusion is additionally replayed by a separate C++ program that exhausts all pulse positions up to the proved bound, using the polynomial A matrices directly. Its complete results are in the independent pulse verification.

Verification and completeness

The alternating-chain identity

Suppose one sign vanishes on row i, and the other sign has exactly one monomial zᵃ in that row, in column j ≠ i. For a third row ℓ, put T = N+,ℓi(z⁻¹), U = N−,ℓi(z⁻¹), and V = N+,ℓj(z⁻¹), exchanging signs throughout when necessary. The (i,ℓ) identity is (1 + zᴿ)(T − U) = zᵃV, where R = rᵢ.

Assume T(1) = m + 1, U(1) = m, and V(1) = 2. Split all exponents into cosets modulo Rℤ. On each coset the coefficient recurrence is wₖ + wₖ₋₁ = vₖ. Finite support requires the two unit terms of V to lie on the same coset, at an odd distance. A single term of coefficient two cannot give finite support. Between the two unit terms, the coefficients of T − U alternate +1, −1, …, +1. Disjointness identifies these as the respective coefficients of T and U; their masses make the chain length 2m + 1.

In ascending order of the original polynomial exponents this gives pT,k = pT,0 + 2kR, pU,k = pT,0 + (2k + 1)R, pV,0 = pT,0 + a − R, and pV,1 = pT,m + a. These necessary linear relations settle rank-five constant pair 2067, where m = 8.

Inherited matching spaces and transport encoding

For a principal subdatum satisfying the exterior-column condition above, a match to a classified rank-three, rank-four or rank-five constant pair also imports its complete matching-space equations. Relabeling the exponent variables and exchanging signs transports its saved rational row-reduced equations to the larger datum. The supporting lower-rank record and variable map can be reproduced with principal_relations.py.

An alternative exact multiset encoding uses nonnegative real transport variables tₑ𝒻 between formal exponent terms on the two sides. Their row and column sums are the respective coefficient multiplicities, and tₑ𝒻 > 0 requires e = f. A transport plan exists exactly when the evaluated exponent multisets agree: equal exponents may exchange their mass, and unequal exponents may not. Thus this encoding and the multiplicity encoding have identical feasibility.

Linear elimination and exact multiset reduction

The first Laurent moment of every identity is linear in the exponent variables. Together with the necessary monomial and principal-block equations, these relations are reduced over the rationals. Substituting their row-reduced form into every Laurent exponent and cancelling equal formal terms preserves the identity on this linear space.

If one remaining side has a single exponent value, equality of positive multisets forces every exponent on the other side to equal it. These new linear equations are added and the reduction repeats. Every nonempty iteration increases the linear rank. The final multiset constraints use exact multiplicities; equal minimum and maximum constraints are redundant consequences. There is no bound on the delays or the integer scaling. All 108 rank-six representatives satisfy this reduced encoding.

Separating the connected slice loops

The cycle-length multiset of the terminal vertex permutation is preserved by relabeling, sign exchange, adjacent commuting mutations and cyclic rotation of the mutation loop. A cyclic rotation conjugates the terminal permutation. Two records with different multisets therefore cannot become equivalent under these moves.

For rank five, 42 records have unique cycle-length multisets. The other 13 records form five groups. Within each group the program exhausts cyclic rotations and commuting moves, including both signs, and compares full canonical encodings. All minima differ. The record stores this separating invariant and the exhaustive minimum where needed; it does not assert a universal canonical normal form for the singleton groups.

For rank six, 78 records have unique cycle-length multisets. The remaining 30 form nine groups. Exhaustive comparison gives distinct minima within each group; the largest combined orbit has 46,080 states.

The rank-six slice computation uses the same moves in a compact C++ engine without an orbit-size guard. Its minima and complete orbit sizes agree with the saved Python results in 16 control cases. Compact storage records the upper triangle of a skew-symmetric matrix; the first differing entry of a full row-major comparison is always above the diagonal, so this preserves lexicographic minima. An out-of-range integer stops the calculation instead of truncating it.

The verifier independently checks the constant matrices, supplies rational positive vectors, checks the matching identities and family dimensions, recomputes both reddening certificates and the labelled period, and replays every exclusion or coverage query. Each saved SMT formula has a SHA-256 digest. Distinctness under slice changes is checked using canonical cyclic mutation-loop encodings.

The rank-five and rank-six enumeration and lift checks have no unresolved cases. The stored certificates establish periodicity and slice distinctness for every surviving family.

Reproduction

The scripts use Python with SymPy and Z3, plus SageMath 10.8 for interval spectra and quiver recognition. The C++ enumerator uses exact 128-bit integers. Its lower-rank controls and all completed upper-triangle outputs are retained.

From the repository root in WSL, the enumeration command is:

mkdir -p research/higher_rank/bin
g++ -O3 -std=c++17 -Wall -Wextra \
  -fsanitize=signed-integer-overflow \
  -fno-sanitize-recover=signed-integer-overflow \
  research/higher_rank/enumerate_constants.cpp \
  -o research/higher_rank/bin/enumerate_constants_hereditary
python3 research/higher_rank/run_constants.py 6 --workers 16 \
  --binary enumerate_constants_hereditary \
  --principal-file research/higher_rank/principal-constants.txt

Extract the relevant constant_tasks.zip into that rank’s constant_tasks/ directory to reuse completed tasks in a fresh checkout. The driver skips completed upper-triangle tasks and charges new computation against the existing ledger. The per-rank computation-policy.json overrides the default allowance. A null time_limit_seconds permits the calculation to finish without a wall-clock cutoff.

For a new rank whose constant enumeration completes, run_lifts.py provides the sequential lifts, families and verify stages. It retains timeouts as unknown. The --retry option retries unresolved cases. Each recorded query is stored with its arithmetic convention and SHA-256 digest. Analytic exclusions depend on the displayed lemmas; a saved false formula alone is not their proof.

build_records.py checks completion before marking the classification complete, and docs/catalogue/build_catalogue.py admits higher-rank records only from a completed classification. The exact spectrum and quiver verifiers run before finish_enrichment.py assembles the catalogue records. Browser checks verify display and interaction.

RSG notes use the source-faithful transcription in research/catalogue/family_notes.py, with nonexistent predecessor terms set to zero; SG notes use the frozen Sage constructor directly. Every named instance is independently checked as a polynomial T-datum before its exact rescaling, shift and permutation match is recorded.
